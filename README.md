# UstaFlow Lite

UstaFlow Lite, teknik servis ve saha ekiplerinin müşteri kayıtlarını, servis taleplerini, personel atamalarını ve görev durumlarını tek panel üzerinden yönetmesini sağlayan web tabanlı bir sistemdir.

## Teknolojiler

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- Auth.js

## Proje Süresi

Proje, tek geliştirici tarafından 4 haftalık MVP süreci kapsamında geliştirilecektir.
